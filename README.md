Hello this is just a simple project of using N8N as a way to create a chat bot using tokens of pre-existing AI
Such as Gemini,Chatgpt and more.

![](images/screenshot)


You can ask stuff to the bot by running the n8n workflow first then ask anything in the html file!

![](images/screenshot1)



Keep in mind this project/bot doesn't cover all of convertation types since to add more type you need to add it in the code.
Because of how the bot works needing chat categories to reply, if it doesn't exist the workflow will stop.
